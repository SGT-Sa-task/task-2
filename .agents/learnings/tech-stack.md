# Tech Stack Summary

- **Ngôn ngữ cốt lõi:** Python 3.x
- **UI Framework:** Streamlit (Hiển thị giao diện web tương tác trực tiếp từ mã Python).
- **Xử lý Dữ liệu:** `pandas` (Hỗ trợ đọc, lọc và xử lý dữ liệu bảng trước khi đồng bộ).
- **Giao tiếp API & Xác thực:**
  - `requests`: Xử lý HTTP requests đến hệ thống HubSpot.
  - `gspread`: Tương tác với Google Sheets API.
  - `oauth2client`: Quản lý xác thực Google Service Account để truy cập file Sheet an toàn.
- **Môi trường dev:**
  - `pytest`: Framework kiểm thử.
